Vault

Decide which tools your team’s agents can use. Every call recorded.

When everyone’s agents work together, they share the company’s tools. Vault keeps that safe: admins connect tools once, people sign in with the company account, and every call is checked against the groups and rules you set.

How it works

Connect once. Every call checked.

  1. Connect tools once

    An admin connects a tool (an MCP server) and approves what it can do. Connecting it gives nobody access yet.

  2. Give access by group

    Access is off by default. Give a group single tools or whole servers, and add rules on what a tool may be asked.

  3. Share keys without pasting them

    A group's agents use a shared key at run time; nobody passes it around in chat.

  4. Every call is recorded

    Each call is checked against the current groups and rules, and logged with the person and the agent that made it.

FAQ

Questions, answered.

Is Vault part of every setup?

Yes. It comes with AgentWorks and we set it up with you, together with the Team kit your teams share.

Which AI tools work with it?

Any tool that can connect to a remote MCP server, such as Claude, ChatGPT, Cursor and your team's agents. People sign in with the company account, and a tool can be disconnected at any time.

Does connecting a tool give people access?

No. Access is off by default. A tool reaches people only through the groups an admin gives it to, and new or changed tools wait for review.

Can agents see a shared key?

An agent receives the key when it runs, so it can use it. What Vault stops is keys being pasted into chats and files, and use by people outside the group.

Where does it run?

On your AgentWorks server, on your own infrastructure.

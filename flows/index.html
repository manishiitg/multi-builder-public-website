Flows Enterprise

The same steps, every time. Run them from anywhere.

Some jobs don't need an agent that plans. They need the same few steps, done well, every time: read the enquiry, decide what it is, look something up, write the reply. Flows let you chain agents, decisions and small scripts into one simple sequence, then call it from your website, your CRM or any other system. Share it, and your team runs it from its dashboard.

FAQ

Questions, answered.

How do I publish a new version?

Edit the draft in the Flow Builder and publish. Each publish freezes a numbered version behind the same endpoint, so callers can pin a version or follow the latest.

How is a Flow different from a Goal?

A Goal works toward a number: it plans, measures and adjusts its own steps, and shows whether the metric moves. A Flow is fixed. It runs the same steps in the same order every time, which is what you want behind a website form or another system.

What can a step be?

An agent step with its own system prompt and message, a classifier that sorts the input into the categories you name, a condition that decides which step runs next, or a script step for exact work like formatting data or calling an API. Steps pass their output to the next one.

How does a Flow send a request the right way?

Add a classifier step. You list the categories, such as billing, support or sales, with a line on what belongs in each, and the Flow sends each request to that category's branch. The diagram shows which way every run went.

Who can run a Flow I share?

Anyone you share it with opens its dashboard and can ask it questions or run the published version. Only you change the steps.

How do other systems run a Flow?

Each deployed Flow gets a trigger: an authenticated API endpoint or webhook. Your website, CRM, backend or no-code tool sends the input and gets the result back, or a callback when it finishes.

Which models run the agent steps?

The same AI plans you connect to AgentWorks, such as Claude, ChatGPT, Gemini or Cursor. You can choose a different one per step.

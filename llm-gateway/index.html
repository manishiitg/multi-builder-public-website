FAQ

Questions, answered.

Is it available?

Not yet. LLM Gateway is coming soon. Book a call and we will set it up with you when it opens.

How do apps call it?

Through one endpoint on your AgentWorks server: list the models, then send messages or responses requests. Each person or app uses their own token.

What can a token do?

Only list models and run them. It can't change settings or reach the admin screens, and the person's current model access still applies on every call.

Does it replace Vault?

No. Vault governs MCP tools and shared secrets. LLM Gateway governs model calls. They run side by side on your server.

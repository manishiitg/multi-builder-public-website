How it works

You set the target. The agents keep working until it's hit.

  1. Set the goal

    Pick a premade agent or describe the outcome, then agree the metric and target with us.

  2. Run

    Agents work through your tools on a schedule, with your approval on anything that goes out.

  3. Measure

    Every run records what it did and what it moved, so you see progress, not activity.

  4. Auto-improve

    It fixes what broke, drops what didn't work and tries the next idea.

FAQ

Questions, answered.

Can it change orders in Shopify?

Only what you grant. Reading orders is the default; updates, refunds and customer messages can each require your approval.

Does it work with my apps?

If an app has an API, an MCP server or a web page, an agent can use it.

What about refunds?

Refunds above the limit you set always wait for you, with the order and the conversation attached.

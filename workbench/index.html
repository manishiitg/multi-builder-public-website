How it works

One server for every agent. Chat or terminal, your choice.

  1. Connect the plans once

    An admin connects your Claude, ChatGPT, Cursor and other plans on the server as shared accounts. Anyone can still add a private account for their own work.

  2. Give each team its Crew

    Set up shared Crew agents with the skills, memory and tools each team needs. People reach them in chat, Slack or WhatsApp.

  3. Chat or the live terminal

    Work in plain chat, or switch to the vendor's own CLI running live in a terminal on the server. Every command it runs is sandboxed to the folders it is granted.

  4. Measure and govern

    See recorded usage and cost by user, Crew, workflow and model. Roles, per-workflow access and a full run log keep it governed.

FAQ

Questions, answered.

Can we share one subscription across people?

That depends on the plan. Team, business and enterprise plans and API keys are made for shared use; personal plans usually are not, so check each vendor's terms. AgentWorks runs whichever accounts you connect.

Can people still use their own plan?

Yes. Anyone can add a private account for their own work, next to the shared server account an admin manages.

How is usage measured?

Every agent call is recorded with its user, Crew or workflow, provider and model, with token counts and cost. Subscription usage shows as a subscription-equivalent estimate, not as your bill.

Can one person's agent reach another person's files?

Not through the commands it runs. Every shell command and script gets its own private /tmp and runs in a Linux sandbox limited to the folders its workflow or Crew was granted, and it can't reach other people's agent terminals. Each workflow or Crew also has its own home folder, so git logins, SSH keys and CLI settings stay with it.

What does the terminal mode give power users?

The vendor's own CLI, such as Claude Code, Codex or Cursor, running live on the server, with every command it runs sandboxed. They get the full tool without it touching their laptop, and every run is logged.

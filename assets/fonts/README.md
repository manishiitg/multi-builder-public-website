# Local Font Assets

This site self-hosts the Latin WOFF2 subsets used by the marketing pages:

- Space Grotesk, sourced from Google Fonts / Florian Karsten Typefaces.
- JetBrains Mono, sourced from Google Fonts / JetBrains.

Both typefaces are distributed under the SIL Open Font License 1.1. See the upstream family pages for the full license and attribution text:

- https://fonts.google.com/specimen/Space+Grotesk
- https://fonts.google.com/specimen/JetBrains+Mono
